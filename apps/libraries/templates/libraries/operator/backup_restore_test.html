Test Steps
  1. Generate Test Data - Create random files with specified size
  2. Create Checksums - Calculate SHA256 for each file
  3. Mount Tape - Load tape from slot to drive
  4. Backup to Tape - Write data using tar
  5. Unmount Tape - Unload tape back to slot
  6. Mount Tape (Again) - Reload tape for restore
  7. Restore from Tape - Extract data to temp directory
  8. Unmount Tape (Final) - Unload tape
  9. Verify Checksums - Compare restored files against originals
  10. Cleanup - Remove temporary test files
Warning: This test will write data to the selected tape. Make sure you select a tape that can be overwritten.
