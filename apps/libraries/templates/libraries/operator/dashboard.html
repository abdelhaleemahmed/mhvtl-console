Tape Operations

{% comment %} One page, both directions - see guides/plan-mount-unmount. Two buttons to the same place said there were two jobs. {% endcomment %} Mount / Unmount Tape Move Tape
{% comment %} Its own group. LTFS used to sit under Tape Operations, on the grounds that it is mounting a cartridge one step further than the robot does - true, but it undersold what is there. The LTFS page reads drive and volume status, mounts and unmounts a filesystem, checks one, provisions an LTFS-capable drive and creates media for it. That is not one more tape operation; it is a set of them, against a different thing - a filesystem rather than a robot. The two "mounts" are the reason to keep them apart on the menu as well as on the page: Tape Operations moves a cartridge into a drive, LTFS Operations opens what is in the drive as a filesystem. See guides/architecture, "Two different things are called mount". {% endcomment %}
